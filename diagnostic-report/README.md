# BET 2026 Diagnostic model report

Build the report from the repository root:

```sh
bash diagnostic-report/run.sh
```

The output directory contains a self-contained HTML report, an offline
interactive viewer, publication-resolution PNG/PDF figures, CSV tables and a
compact RDS file with the native MFCL delta-method results. Set
`REPORT_OUTPUT_DIR` to choose another output directory. Set
`DIAGNOSTIC_MODEL_DIR` when the raw fitted model files are staged elsewhere by
Kflow.

The committed `results/reference/uncertainty/bet.var` was generated by the
matching MFCL executable from the archived final PAR and complete Hessian using
the intermediate native derivative set (`parest flag 37 = 2`). It covers the
full spawning-potential, recruitment and dynamic-depletion time series plus the
recent management quantities.
